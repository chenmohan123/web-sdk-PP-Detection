# Detection 示例与缓存整改

范围为单 SDK。沿用标准 v1 的 SDK、Demo、Examples 契约，不修改门户或其他 SDK。

1. 先复现延迟下载与当前/全部清理竞态，以及示例缺失模型参数的问题。
2. 按缓存存储范围共享失效代次，串行化读写和清理；覆盖跨管理器、清理后新写入、失败恢复。
3. 每个示例固定公开 SDK 0.1.1 和 ModelScope 当前官方模型清单，补安装/启动/构建说明与取消、重复点击、卸载释放。
4. Demo 展示真实缓存容量，提供当前模型与全部本 SDK 缓存清理；同步互斥，取消并等待在途操作，释放会话后刷新。
5. 执行 SDK/Demo 测试、独立消费者原样安装构建、真实模型初始化和一次推理；证据区分本地模型网络隔离与外网访问。

不在本轮扩大耗时、后端报告或视频性能整改范围。视频迟到启动仅为清理生命周期补充取消保护。
