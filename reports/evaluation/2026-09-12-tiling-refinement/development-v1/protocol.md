# 第二轮切片实验预设规则

本轮是用户确认的可行性实验延续；使用 SDK 0.3.2 与六个正式模型，产品代码不变。先在上一轮 COCO 64 图原始输出上比较有限的合并策略，再锁定一个统一策略，最后运行未参与策略选择的真实高分辨率标注图片。

诊断保留整图、原始组合两个基线，并比较三个预设候选，不做阈值网格搜索：

1. `whole-first`：完整保留整图框，切片框按 score 降序补充，凡与已经保留的同类框 IoU > 0.5 即抑制。用于识别优先保留整图的收益与代价。
2. `edge-contained`：在上项基础上，丢弃贴近切片内部边缘（边距为片长/宽的 2%）的框；若候选与已有同类强框（score ≥ 0.5）的交集/较小框面积 > 0.8，也抑制。外侧原图边缘不作截断处理；不跨类别去重。
3. `small-additions`：在上项基础上，切片补充框的宽、高分别不得超过原图宽、高的 25%，控制大物体片段的加入。原图框仍全部保留。

全部框使用原 score，不因来源人为改变置信度；AP 最低 score 0.001，固定阈值匹配为 score ≥ 0.5、IoU ≥ 0.5。保留逐框来源、剔除原因、数量及丢失/新增 GT。三个候选都必须复用原始框重算，不重新跑相同 COCO 推理。

先仅在两模型 FP32 WebGPU 上选择策略。目标为：相对整图，AP 下降不超过 0.5 点、大目标 AP 下降不超过 2 点；FP 增量不超过 max(10, 整图 FP×20%)；保留至少 80% 原始组合的额外小目标命中。如果存在两模型均满足的候选，按总小目标命中降序、总 FP 升序选择。若不存在，明确报告门槛未通过；在至少保留 50% 两模型合计额外小目标命中的候选中选择总 FP 最少者作诊断性独立验证，不宣称满足产品目标。若连 50% 都无法保留，则选择小目标命中最多者，并报告收益未保留。

冻结策略、选择结果与脚本 SHA256 后，才对独立样本执行推理。独立集使用真实高分辨率标注图，不把原 COCO 图片放大作为新样本。数据集类别、忽略区域及 COCO 类别映射另行锁定；跨数据集 AP 不直接横向排名。最多选 32 张固定种子图片，先按元数据保证长边至少 1280、小目标及大目标场景覆盖，记录原始来源/许可/哈希。不得根据检测结果换图或重新调参。

独立集比较整图、原始组合、冻结候选。固定 2×2 与 20% 重叠；浏览器逐组合串行，先完整预热一图。六模型 WebGPU 均验证；两模型 FP32 补 WASM 对照。沿用正式 SDK、原始 RGBA 裁切及坐标还原。记录逐图处理时间及合并时间，模型读取与初始化单列。评价范围、类别转换和样本分布在报告中说明。

本轮交付包含原始策略比较、独立样本结果、收益与失败案例、测试及可复现脚本。产品目标未通过时，输出结论与后续选项，不直接接 SDK 或 Demo。
