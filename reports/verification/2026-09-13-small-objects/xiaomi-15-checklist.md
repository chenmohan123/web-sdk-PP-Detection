## 先验收 PP-YOLOE / FP32 / GPU

- [ ] 打开本地开发 Demo，来源默认 ModelScope；「小目标增强（实验）」默认不勾选。
- [ ] 选择一张含远处行人、车辆等小目标的静态图片，先普通检测，再勾选增强检测。
- [ ] 增强时状态行出现 `检测中 0/5` 至后续进度，图片和结果区位置不因进度变化跳动；完成后可再次检测。
- [ ] 对照原图检查是否补出有意义的小目标、是否出现明显重框或碎片；同时记录新增误检，不能仅比较框数量。
- [ ] 点击列表/图片定位同一目标，框和标签位置正确，导出 PNG 与 JSON 正常；JSON 增强结果含 `smallObjectEnhancement.passes`。
- [ ] 连续运行 3 次，未出现崩溃、页面重载或耗时持续明显增长；记录本次端到端和推理时间。

## 取消、切换与资源

- [ ] 增强运行中点击取消，不出现迟到结果；重新检测可以完成。当前单次推理可能需要先结束。
- [ ] 取消后更换图片或模型，结果属于新输入；清理当前模型缓存后可重新加载。
- [ ] 关闭增强后普通检测恢复，导出的新 JSON 不含增强字段。
- [ ] 切到视频/摄像头模式时不显示增强开关；回到图片模式仍可调整开关。
- [ ] 横竖屏及中英切换无横向溢出，控件可触摸，识别结果可查看。
